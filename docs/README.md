## Phần cứng

Toàn bộ tài liệu ESP32 và phần cứng nằm trong [Hardware](Hardware/README.md).

Bao gồm:

- ESP32-S3
- Biên dịch firmware
- Ghép firmware APP/FULL
- Nạp firmware qua USB
- Cập nhật OTA
- GPIO / Pinout
- Microphone / I2S
- Loa / Audio
- LED WS2812
- Nút nhấn
- Các tài liệu phần cứng bổ sung sau này
